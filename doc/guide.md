# 使用指南

Douban Import 将豆瓣资料与个人收藏记录写入 Obsidian。先设置保存位置，再选择导入或同步；个人收藏和部分页面需要登录。

## 安装

当前开发基线可从源码构建。使用 Node.js 22：

~~~bash
git clone https://github.com/threeyang3/douban-import.git
cd douban-import
npm ci
npm run build
~~~

将 `main.js`、`manifest.json`、`styles.css` 放入 Vault 的 `.obsidian/plugins/douban-import/`，重启 Obsidian 并启用 **Douban Import**。使用自定义配置目录时，用它替换 `.obsidian`。

插件声明最低 Obsidian 版本为 **1.4.4**，以使用当前写入流程需要的 API；未据此声称已在所有版本和平台实测。公开 Release 可用后，可以直接下载同名三个附件。

## 先配置保存位置

在插件设置中确认：

- **输出设置**：作品资料保存位置及文件名规则。
- **导入模板**：每类资料使用内置模板、文件模板或自定义内容。
- **附件设置**：封面保存路径；使用图床时填写自己的服务配置。
- **高级设置**：强制替换时的备份与用户数据保护选项。

仓库的 `examples/templates/` 提供继承的示例模板，供参考或复制到自己的 Vault；这些示例不是插件运行时自动扫描的个人数据。

## 登录豆瓣

| 平台 | 提供的登录入口 |
| --- | --- |
| Obsidian 桌面端 | 豆瓣网页登录窗口、二维码、手工 Cookie |
| Obsidian 移动端 | 二维码、手工 Cookie；没有桌面端 Electron 登录窗口 |

**二维码登录**：打开插件“登录”设置，选择二维码登录，在另一台设备上的豆瓣 App 扫码并确认。二维码过期时刷新；以插件返回的登录状态为准。扫码确认不一定立即取得完整用户资料，后续访问仍可能要求重新验证。

**桌面网页登录**：桌面端提供打开豆瓣登录窗口的入口，登录后插件读取当前会话。窗口是否可用受 Obsidian 桌面运行环境及豆瓣页面影响；打不开或不能完成登录时，可使用二维码或 Cookie 入口。

**Cookie 备用方式**：

1. 在自己的桌面浏览器中登录豆瓣，打开豆瓣页面。
2. 打开浏览器开发者工具的 Network 面板，刷新页面，选择发送到豆瓣的页面请求。
3. 从请求头中复制 `Cookie` 的值，不包含字段名 `Cookie:`。
4. 在插件的 Cookie 登录入口粘贴该值，点击确认，查看插件登录状态。

Cookie 是登录凭据，只应粘贴到自己的本地插件中，不应提交到 Issue 或公开日志。插件将登录信息保存在本地配置里；正常配置导出默认排除 Cookie 等凭据。因此，从旧插件导入普通配置后，需要重新登录。

以上说明对应已有实现和界面，不代表本次已完成豆瓣线上登录验证。遇到豆瓣登录、验证或限流页面时，按实际提示处理。

## 搜索和批量导入

打开 Obsidian 命令面板，搜索豆瓣相关命令，可以输入关键词、利用当前文件名搜索，或者选择批量 URL 导入。

资料解析支持 **电影、电视剧、书籍、音乐、游戏、舞台剧、豆瓣日记**。电影和电视剧使用相关搜索入口，并在解析时识别页面类型。批量导入每行一个 URL，提供去重、进度、取消和单条失败明细。

可以在模板编辑器中用示例数据查看实时预览，再将自定义内容保存为文件模板。模板会影响新生成的内容，改变模板本身不会自动改写已有笔记。

## 同步个人收藏

当前同步界面提供 **电影、电视剧、书籍、音乐、游戏**。舞台剧和豆瓣日记支持资料导入，但不因此具备完整收藏同步入口。

在同步界面选择类型、状态和日期范围。同步处理全部已选范围；普通流程按既有规则处理新增和已有条目，强制替换会先展示创建、替换、跳过计划。执行前核对预览以及“保留用户属性 / 记录 / 感想”和备份选项。

同名条目不应直接互相覆盖；同步结果会记录冲突、失败和处理结果。发生单条失败时，查看结果报告后再决定重试范围。

## 记录个人笔记与迁移用户数据

当前笔记命令可为当前作品创建或继续本地笔记，也可关联已有笔记或其中的标题。它使用现有作品字段和笔记链接，尚不是未来独立 Work/Note 模型的实现。

“导出/导入用户数据”用于迁移作品中的个人属性和记录/感想分区；“高级 → 导出/导入配置”用于插件设置。两者用途不同。用户数据导入支持选择条目、比较字段和选择合并策略。

已有旧插件用户请按[迁移说明](./migration.md)切换，避免两个插件同时对相同笔记同步。
