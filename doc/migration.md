# 从 douban-sync 迁移

旧插件 ID 为 `obsidian-douban-plugin`，新插件 ID 为 **`douban-import`**。新身份会分开保存插件设置及快捷键，但不会自动重写你的 Markdown。

## 推荐流程

1. 在旧插件的“高级 → 导出配置”保存配置 JSON。
2. 停用旧插件，保留其目录和配置以便回退。
3. 安装并启用 Douban Import，在“高级 → 导入配置”选择刚导出的文件。
4. 重新登录豆瓣。普通配置导出默认排除登录凭据。
5. 核对作品输出路径、文件模板、附件位置、备份目录和数据保护选项。
6. 在 Obsidian 的快捷键设置中，把常用操作重新绑定到 Douban Import 命令。

已有 Markdown、图片、模板和个人笔记保留原位置，不需要重新抓取或导入整个资料库。先对一条既有作品查看预览，确认路径与效果后再恢复日常同步。请避免两个插件同时写入同一批笔记。

## 保持兼容的内容

| 内容 | 处理方式 |
| --- | --- |
| `doubanId` 等已有字段 | 保持原含义，不改成新的 Work UID |
| 笔记正文与个人字段 | 保留原文件，继续使用已有数据保护设置 |
| 文件模板、附件和输出目录 | 尊重导入配置中的显式路径；相关文件须仍然存在 |
| 配置与用户数据 JSON | 继承已有格式，格式版本不随插件版本重启 |
| 登录凭据 | 默认不在导出配置中，重新登录 |
| 快捷键 | 命令完整 ID 的插件前缀已变化，需要重新绑定 |

新插件版本为 `0.1.0` 不表示原数据被降级或重置。

## 新默认目录

| 用途 | 默认位置 |
| --- | --- |
| 插件与本地配置 | `.obsidian/plugins/douban-import/` |
| 临时文件与同步报告 | `.tmp/douban-import/` |
| 替换前备份 | `.tmp/douban-import/backups/` |
| 写入内置模板的默认目录 | `Templates/Douban-Import/` |

已导入的显式旧路径优先保留。例如原配置指定 `.tmp/obsidian-douban/backups`，导入后仍可使用该路径，不会自动移动已有备份。自定义 Obsidian 配置目录相应替换 `.obsidian`。

常规迁移无需手动编辑 `data.json` 或 `community-plugins.json`。若新插件已经有自己修改过的设置，先导出一份再导入旧配置。

## 回退

停用 Douban Import，重新启用保留的旧插件。新插件不会覆盖旧 ID 下的配置；但运行新插件期间对 Markdown 做出的实际修改仍会保留，需要恢复某次替换前的内容时，使用相应备份。

后续引入 Work、Series 和来源映射时会另外设计迁移方式。本次切换不会自动生成新 UID、拆分作品或批量转换页面类型。
