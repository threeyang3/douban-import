# Douban Import

Read [AGENTS.md](AGENTS.md) for the repository's shared instructions.

This is the independently maintained `douban-import` project. It reorganizes the `douban-sync/adv` baseline into its own application and feature modules while preserving existing functionality and persisted data formats.

Source attribution is in `PROVENANCE.md`. Current responsibility boundaries and future model decisions are in `doc/architecture.md`. Follow the actual public code and the current user request; do not treat roadmap items as shipped features or copy private architecture materials into the repository.
